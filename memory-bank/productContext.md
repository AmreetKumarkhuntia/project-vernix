# Product Context: Svelte UI Library

## Purpose

- Standardize UI development across projects
- Reduce duplicate component creation
- Ensure accessibility compliance
- Speed up development with ready-to-use components

## User Experience Goals

- Consistent interaction patterns
- Clear visual hierarchy
- Responsive behavior
- Accessible by default

## Component Philosophy

1. **Composable** - Components work well together
2. **Configurable** - Props control behavior
3. **Customizable** - Themes and CSS variables
4. **Documented** - Clear usage examples

## Key User Flows

1. Component selection
2. Props configuration
3. Theme application
4. Integration into apps

## Design Principles

- Minimalist aesthetic
- Functional over decorative
- Mobile-first approach
- Performance conscious
