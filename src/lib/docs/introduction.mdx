# Vergins: A Svelte UI Library

Vergins is a reusable, accessible, and themeable UI component library for Svelte applications. It provides a set of foundational and specialized components to help you build beautiful and consistent user interfaces with ease.

### Features

- **Reusable Components:** A collection of ready-to-use components to speed up your development process.
- **Accessible by Default:** Components are designed with accessibility in mind, including keyboard navigation and ARIA support.
- **Themable:** Easily customize the look and feel of the components using CSS variables.
- **Consistent Design:** All components follow a consistent design pattern to ensure a cohesive user experience.
- **TypeScript Support:** All components are written in TypeScript for a better development experience.

### Available Components

##### Foundation Components

- Buttons
- Inputs
- Cards
- Navigation (Navbar, Breadcrumbs)
- Layout (Accordion, Modal)

##### Specialized Components

- FileUploader
- Flyer
- LazyLoader
- Timeline
- Carousel

### Usage

Here's a basic example of how to import and use a component from the library:

<Code 
lang="jsx"
code={`<script>
  import 'vergins/css/improved-theme-2';
  import { Button } from 'vergins';
</script>

<Button onClick={() => alert('Button clicked!')}>
  Click me
</Button>`}/>

### Theming

vergins comes with two pre-built themes:

- `default-theme`
- `improved-theme`
- `improved-theme-2`

To use a theme, import it in your main `+layout.svelte` or `+page.svelte` file:

<Code 
lang="jsx"
code={`<script>
  import 'vergins/css/improved-theme-2';
</script>`}/>

You can also customize the theme by overriding the CSS variables defined in the theme files.

## API Reference

##### Global Props

Most Vergins components support these common props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `componentClass` | `string` | `''` | Additional CSS classes for custom styling |
| `disabled (to be added as per need)` | `boolean` | `false` | Disables component interactions |
| `size (to be added)` | `'small' \| 'medium' \| 'large'` | `'medium'` | Controls component size |

##### Event Handling

All interactive components emit standardized events:

| Event | Description | Payload |
|-------|-------------|---------|
| `onClick (to be added as per need)` | User interaction event | `MouseEvent` |
| `onChange (to be added as per need)` | Value change event | `CustomEvent` |
| `onFocus (to be added as per need)` | Focus gain event | `FocusEvent` |
| `onBlur (to be added as per need)` | Focus loss event | `FocusEvent` |

## Best Practices

##### Component Organization

1. **Import Strategy**: Import only the components you need to optimize bundle size
2. **Theme Consistency**: Use a single theme throughout your application
3. **Custom Styling**: Use `componentClass` prop for component-specific styles
4. **Accessibility**: Always provide proper labels and ARIA attributes

##### Performance Optimization

<Code 
lang="jsx"
code={`<script>
import { Button, InputField } from 'vergins';

import * as Vergins from 'vergins';

import Button from 'vergins/components/Button';
</script>`}/>

## Troubleshooting

#### Common Issues

**Components not displaying correctly**
- Ensure you've imported the CSS theme file
- Check that CSS custom properties are defined
- Verify component imports are correct

**TypeScript errors**
- Make sure you have the latest version installed
- Check that your TypeScript configuration includes the component types
- Verify prop types match the component interface

**Styling conflicts**
- Use CSS specificity or `!important` for overrides
- Check for conflicting CSS frameworks
- Use `componentClass` for component-specific styling

#### Browser Support

Vergins supports all modern browsers:
- Chrome 70+
- Firefox 65+
- Safari 12+
- Edge 79+

#### Performance Tips

1. **Lazy Loading**: Use dynamic imports for large components
2. **Bundle Optimization**: Configure your bundler for tree-shaking
3. **CSS Optimization**: Use PostCSS for CSS optimization
4. **Image Optimization**: Optimize images used in components
