# Avatar Component

The `Avatar` component is used to represent a user.

## Basic Usage

<Code 
lang="jsx"
code={`<script>
  import "vergins/css/improved-theme-2";
  import { Avatar } from 'vergins';
</script>

<Avatar src="https://example.com/avatar.png" alt="User Avatar" />`}
/>

## API Reference

##### Props

| Prop           | Type                                           | Default        | Description                                                |
| -------------- | ---------------------------------------------- | -------------- | ---------------------------------------------------------- |
| `src`          | `string`                                       | `''`           | The source URL for the image avatar.                       |
| `alt`          | `string`                                       | `'User Avatar'`| The alt text for the avatar. Used for the initial if no `src` is provided. |
| `dataType`     | `'image' \| 'svg' \| 'user'`                   | `'image'`      | The type of avatar to display.                             |
| `size`         | `string`                                       | `'50px'`       | The size of the avatar.                                    |
| `onClick`      | `(e: MouseEvent, elementType: string) => void` | `() => {}`     | A callback function when the avatar is clicked.            |
| `smallSize`    | `string`                                       | `'16px'`       | The size of the avatar on small screens.                   |
| `letterColors` | `Record<string, string>`                       | `{...}`        | A map of letters to background colors for initial avatars. |

##### Slots

| Name      | Description              |
| --------- | ------------------------ |
| `default` | The content for an SVG avatar. |
