# Button

The `Button` component is a simple, versatile button that can be used for various actions.

## Usage

<Code 
lang="javascript"
code={
  `
<script>
  import Button from 'project-vernix/Button.svelte';
</script>

<Button on:click={() => alert('Button clicked!')}>
  Click me
</Button>
`
}
>
</Code>

## Props

- `size`: `'small' | 'medium' | 'large' | 'fill'` (default: `'medium'`) - The size of the button.
- `type`: `'filled' | 'outlined'` (default: `'filled'`) - The type of the button.
- `disabled`: `boolean` (default: `false`) - Disables the button.
- `componentClass`: `string` (default: `''`) - Additional classes to apply to the button.
