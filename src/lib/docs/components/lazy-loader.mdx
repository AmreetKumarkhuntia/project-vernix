# LazyLoader Component

The `LazyLoader` component is used to lazy load content.

## Basic Usage

<Code 
lang="jsx"
code={`<script>
  import "vergins/css/improved-theme-2";
  import { LazyLoader } from 'vergins';
</script>

<LazyLoader>
  <p>This content will be loaded lazily.</p>
</LazyLoader>`}
/>

## API Reference

##### Props

| Prop            | Type             | Default                  | Description                               |
| --------------- | ---------------- | ------------------------ | ----------------------------------------- |
| `lazyLoaderProps` | `LazyLoaderProps`| `defaultLazyLoaderProps` | An object of lazy loader properties.      |
| `className`     | `string`         | `''`                     | A class name to apply to the component.   |
| `maxCount`      | `number \| null` | `null`                   | The maximum number of times the content can be loaded. |

##### `LazyLoaderProps`

| Prop            | Type                | Description                               |
| --------------- | ------------------- | ----------------------------------------- |
| `inTransition`  | `TransitionWrapper` | The in transition for the content.        |
| `outTransition` | `TransitionWrapper` | The out transition for the content.       |

##### Slots

| Name      | Description              |
| --------- | ------------------------ |
| `default` | The content to be loaded lazily. |
