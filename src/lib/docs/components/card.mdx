# Card Component

The `Card` component is a flexible and extensible content container.

## Basic Usage

<Code 
lang="jsx"
code={`<script>
  import "vergins/css/improved-theme-2";
  import { Card } from 'vergins';
</script>

<Card title="Card Title">
  <p>Card content</p>
</Card>`}
/>

## API Reference

##### Props

| Prop    | Type     | Default | Description              |
| ------- | -------- | ------- | ------------------------ |
| `title` | `string` | `null`  | The title of the card.   |

##### Slots

| Name      | Description              |
| --------- | ------------------------ |
| `default` | The content of the card. |
