# Toggle Component

The `Toggle` component is a switch that can be turned on or off.

## Basic Usage

<Code 
lang="jsx"
code={`<script>
  import "vergins/css/improved-theme-2";
  import { Toggle } from 'vergins';
  let toggled = false;
</script>

<Toggle bind:toggled />`}
/>

## API Reference

##### Props

| Prop      | Type      | Default | Description                       |
| --------- | --------- | ------- | --------------------------------- |
| `toggled` | `boolean` | `false` | Whether the toggle is on or off. |
